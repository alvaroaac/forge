# Phase 1 MVP Plan Addendum

## Tooling Scope

- Repo-wide tooling added in Task 1b must not rewrite or lint source-of-truth reference/protocol directories unless a later task explicitly owns them.
- Treat `.agents/`, `thoughts/`, `resources/design/`, and `scripts/orchestrator-core/` as reference or handshake material for Phase 1 app development.
- `npm run format` and `npm run lint` should pass by scoping or ignoring those reference/protocol directories, not by reformatting or refactoring them.
- Task progress/review artifacts under `thoughts/tasks/**/impl/` may be written by the subagent workflow, but formatting commands should not rewrite them opportunistically.
